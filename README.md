## 📌 About

The starting point of the Node.js track at Rocketseat **Ignite**, kept in `fundamentos-nodejs/`.

## 🧠 What I practiced

- **HTTP methods** and when to use each.
- **Route params, query params and request body** in Express.
- **Live reload** with nodemon.

## 🚀 Run locally

You need Node.js and Yarn (or npm).

```bash
git clone https://github.com/wanderson1873/Rocketseat.git
```

Runs on `http://localhost:3333`:

```bash
cd Rocketseat/fundamentos-nodejs
yarn install
yarn dev
```
